## ⚠️ 注意事项

### 1. 枚举值处理
所有枚举类型已定义为Java枚举类，前端传递枚举名称（如"MAVEN"），后端自动映射。

### 2. JSON字段
使用JPA的JSON映射功能，直接将Java对象映射到数据库JSON字段，无需手动序列化。

### 3. 审计字段
所有实体均包含租户ID、创建人、创建时间、修改人、修改时间。

### 4. 分页响应
统一使用PageResponse结构，包含total和list。

### 5. 删除操作
DELETE接口返回204状态码，响应体为空。

### 6. 创建/更新操作
POST/PUT接口返回完整的实体对象。
