# 仓库设置接口文档

## 概述
本文档定义了仓库级别设置相关的RESTful API接口，包括通用设置、存储配置、Webhook管理等功能。

---

## 1. 查询全局仓库配置

### 接口信息
- **接口路径**: `GET /api/v1/repository-settings`
- **接口描述**: 查询全局仓库默认配置
- **权限要求**: `REPOSITORY_SETTINGS_VIEW`

### 请求参数
无

### 响应参数

#### GlobalRepositorySettingsVo
```java
public class GlobalRepositorySettingsVo {
    private String defaultRepository;
    private Boolean anonymousAccess;
    private Boolean indexingEnabled;
    private Boolean compressionEnabled;
    private StorageQuotaVo storageQuota;
    private RetentionPolicyVo retentionPolicy;
}
```

#### StorageQuotaVo
```java
public class StorageQuotaVo {
    private Long quotaGb;               // 配额（GB）
    private Long usedGb;                // 已使用（GB）
    private Integer usage;              // 使用率百分比
}
```

#### RetentionPolicyVo
```java
public class RetentionPolicyVo {
    private Integer retentionDays;
    private Boolean autoCleanup;
    private Boolean deduplicationEnabled;
}
```

### 响应示例
```json
{
  "code": "S",
  "message": "成功",
  "data": {
    "defaultRepository": "maven-central",
    "anonymousAccess": false,
    "indexingEnabled": true,
    "compressionEnabled": true,
    "storageQuota": {
      "quotaGb": 500,
      "usedGb": 128,
      "usage": 26
    },
    "retentionPolicy": {
      "retentionDays": 90,
      "autoCleanup": true,
      "deduplicationEnabled": true
    }
  },
  "timestamp": "1737270600000"
}
```

## 3. 创建Webhook

### 接口信息
- **接口路径**: `POST /api/v1/repository-settings/webhooks`
- **接口描述**: 创建全局Webhook
- **权限要求**: `WEBHOOK_CREATE`

### 请求参数

#### WebhookCreateDto
```java
public class WebhookCreateDto {
    @NotBlank
    private String name;
    
    @NotBlank
    @Pattern(regexp = "^https?://.*")
    private String url;
    
    @NotEmpty
    private List<WebhookEvent> events;
    
    private String secret;              // Webhook密钥（可选）
    
    private Boolean active;             // 默认true
}
```

#### WebhookEvent（枚举）
```java
public enum WebhookEvent {
    ARTIFACT_UPLOAD("artifact.upload"),
    ARTIFACT_DOWNLOAD("artifact.download"),
    ARTIFACT_DELETE("artifact.delete"),
    SCAN_COMPLETE("scan.complete"),
    VULNERABILITY_FOUND("vulnerability.found"),
    REPOSITORY_CREATE("repository.create"),
    REPOSITORY_DELETE("repository.delete");
    
    private final String value;
}
```

### 请求示例
```json
{
  "name": "Slack Notifications",
  "url": "https://hooks.slack.com/services/T00000000/B00000000/XXXX",
  "events": ["ARTIFACT_UPLOAD", "ARTIFACT_DOWNLOAD"],
  "secret": "webhook_secret_key",
  "active": true
}
```

### 响应参数

#### WebhookVo
```java
public class WebhookVo {
    private String tenantId;
    private String createdBy;
    private String creator;
    private LocalDateTime createdDate;
    private String modifiedBy;
    private String modifier;
    private LocalDateTime modifiedDate;
    
    private String id;
    private String name;
    private String url;
    private List<WebhookEvent> events;
    private Boolean active;
    private String lastTrigger;         // 相对时间
    private LocalDateTime lastTriggerTime;
    private Integer successCount;
    private Integer failureCount;
}
```

### 响应示例
```json
{
  "code": "S",
  "message": "成功",
  "data": {
    "tenantId": "1",
    "createdBy": "1000001",
    "creator": "John Anderson",
    "createdDate": "2025-01-19T14:30:00",
    "modifiedBy": "1000001",
    "modifier": "John Anderson",
    "modifiedDate": "2025-01-19T14:30:00",
    "id": "webhook_1234567890",
    "name": "Slack Notifications",
    "url": "https://hooks.slack.com/services/T00000000/B00000000/XXXX",
```

## 数据库表设计

### repository_global_settings 表
```sql
CREATE TABLE repository_global_settings (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    default_repository VARCHAR(255),
    anonymous_access BOOLEAN DEFAULT FALSE,
    indexing_enabled BOOLEAN DEFAULT TRUE,
    compression_enabled BOOLEAN DEFAULT TRUE,
    storage_quota_gb BIGINT,
    retention_days INT DEFAULT 90,
    auto_cleanup BOOLEAN DEFAULT TRUE,
    deduplication_enabled BOOLEAN DEFAULT TRUE,
    
    modified_by VARCHAR(64),
    modified_date TIMESTAMP,
    
    UNIQUE KEY uk_tenant (tenant_id)
);
```

### webhook 表
```sql
CREATE TABLE webhook (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    name VARCHAR(255) NOT NULL,
    url VARCHAR(1000) NOT NULL,
    secret VARCHAR(255),
    active BOOLEAN DEFAULT TRUE,
    last_trigger_time TIMESTAMP,
    success_count INT DEFAULT 0,
    failure_count INT DEFAULT 0,
    
    -- JSON字段
    events JSON,                -- List<WebhookEvent>
    
    created_by VARCHAR(64) NOT NULL,
    created_date TIMESTAMP NOT NULL,
    modified_by VARCHAR(64),
    modified_date TIMESTAMP,
    
    INDEX idx_tenant (tenant_id),
    INDEX idx_active (active)
);
```

### webhook_log 表
```sql
CREATE TABLE webhook_log (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    webhook_id VARCHAR(64) NOT NULL,
    event VARCHAR(100) NOT NULL,
    status_code INT,
    success BOOLEAN,
    request TEXT,
    response TEXT,
    response_time BIGINT,
    triggered_at TIMESTAMP NOT NULL,
    
    INDEX idx_webhook (webhook_id),
    INDEX idx_triggered_at (triggered_at DESC),
    
    FOREIGN KEY (webhook_id) REFERENCES webhook(id) ON DELETE CASCADE
);
```

## 注意事项

1. **Webhook安全**: 使用secret对请求进行签名验证
2. **失败重试**: Webhook失败后自动重试3次
3. **超时设置**: Webhook请求超时时间为30秒
4. **日志保留**: Webhook日志保留最近1000条或30天
5. **频率限制**: 每个Webhook每秒最多触发10次
