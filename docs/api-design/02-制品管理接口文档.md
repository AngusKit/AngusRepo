# 制品管理接口文档

## 概述
本文档定义了制品（Artifact）管理相关的RESTful API接口，包括制品的浏览、搜索、下载、删除、版本管理等功能。

---

## 1. 创建制品（上传制品元数据）

### 接口信息
- **接口路径**: `POST /api/v1/artifacts`
- **接口描述**: 创建制品元数据记录（实际文件上传通过专用上传接口）
- **权限要求**: `ARTIFACT_CREATE`

### 请求参数

#### ArtifactCreateDto
```java
public class ArtifactCreateDto {
    @NotBlank
    private String repositoryId;      // 仓库ID
    
    @NotBlank
    private String name;               // 制品名称
    
    @NotBlank
    private String path;               // 制品路径
    
    @NotBlank
    private String version;            // 版本号
    
    private String description;        // 描述
    
    @NotNull
    private Long sizeBytes;            // 文件大小（字节）
    
    private String checksum;           // 文件校验和（SHA256）
    
    private String license;            // 许可证
    
    private List<String> tags;         // 标签列表
    
    private ArtifactMetadataDto metadata;  // 格式特定的元数据
}
```

#### ArtifactMetadataDto
```java
public class ArtifactMetadataDto {
    // Maven特定
    private String groupId;
    private String artifactId;
    private String packaging;
    
    // Docker特定
    private String digest;
    private List<String> layers;
    private String architecture;
    private String os;
    
    // NPM特定
    private String scope;
    private Map<String, String> dependencies;
    
    // PyPI特定
    private String pythonVersion;
    private List<String> classifiers;
    
    // NuGet特定
    private String authors;
    private String projectUrl;
}
```

### 请求示例
```json
{
  "repositoryId": "1",
  "name": "spring-core",
  "path": "org/springframework/spring-core",
  "version": "6.1.0",

  "metadata": {
    "groupId": "org.springframework",

  }

## 6. 查询制品列表

### 接口信息
- **接口路径**: `GET /api/v1/artifacts`
- **接口描述**: 分页查询制品列表，支持多维度筛选和搜索
- **权限要求**: `ARTIFACT_VIEW`

### 请求参数

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| page | Integer | 否 | 页码（从1开始） | 1 |
| size | Integer | 否 | 每页大小 | 10 |
| repositoryId | String | 否 | 仓库ID筛选 | - |
| search | String | 否 | 搜索关键词（名称、路径、描述） | - |
| format | ArtifactFormat | 否 | 制品格式筛选 | - |
| tags | List<String> | 否 | 标签筛选（多个标签用逗号分隔） | - |
| hasVulnerabilities | Boolean | 否 | 是否有漏洞 | - |
| isLatest | Boolean | 否 | 是否最新版本 | - |
| sort | String | 否 | 排序字段 | modifiedDate |
| order | String | 否 | 排序方向（asc/desc） | desc |

### 请求示例
```
GET /api/v1/artifacts?page=1&size=10&repositoryId=1&format=MAVEN&hasVulnerabilities=false&sort=downloads&order=desc

## 数据库表设计建议

### artifact 表
```sql
CREATE TABLE artifact (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    repository_id VARCHAR(64) NOT NULL,
    name VARCHAR(255) NOT NULL,
    path VARCHAR(1000) NOT NULL,
    version VARCHAR(100) NOT NULL,
    description TEXT,
    size_bytes BIGINT NOT NULL,
    checksum VARCHAR(255),
    downloads INT DEFAULT 0,
    stars INT DEFAULT 0,
    license VARCHAR(255),
    is_latest BOOLEAN DEFAULT FALSE,
    
    -- JSON字段
    tags JSON,                    -- List<String>
    versions JSON,                -- List<String>
    vulnerability JSON,           -- ArtifactVulnerabilityVo
    metadata JSON,                -- ArtifactMetadataVo
    
    -- 审计字段
    created_by VARCHAR(64) NOT NULL,
    created_date TIMESTAMP NOT NULL,
    modified_by VARCHAR(64) NOT NULL,
    modified_date TIMESTAMP NOT NULL,
    
    UNIQUE KEY uk_tenant_repo_path_version (tenant_id, repository_id, path, version),
    INDEX idx_tenant_repository (tenant_id, repository_id),
    INDEX idx_tenant_name (tenant_id, name),
    INDEX idx_downloads (downloads DESC),
    INDEX idx_modified_date (modified_date DESC),
    
    FOREIGN KEY (repository_id) REFERENCES repository(id) ON DELETE CASCADE
);
```

### artifact_download_log 表
```sql
CREATE TABLE artifact_download_log (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    artifact_id VARCHAR(64) NOT NULL,
    user_id VARCHAR(64),
    ip_address VARCHAR(50),
    user_agent VARCHAR(500),
    download_date TIMESTAMP NOT NULL,
    
    INDEX idx_artifact (artifact_id),
    INDEX idx_download_date (download_date DESC),
    
    FOREIGN KEY (artifact_id) REFERENCES artifact(id) ON DELETE CASCADE
);
```

### artifact_star 表
```sql
CREATE TABLE artifact_star (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    artifact_id VARCHAR(64) NOT NULL,
    user_id VARCHAR(64) NOT NULL,
    starred_date TIMESTAMP NOT NULL,
    
    UNIQUE KEY uk_artifact_user (artifact_id, user_id),
    
    FOREIGN KEY (artifact_id) REFERENCES artifact(id) ON DELETE CASCADE
);
```

## 错误码定义

| 错误码 | 说明 |
|--------|------|
| ARTIFACT_001 | 制品不存在 |
| ARTIFACT_002 | 制品已存在（相同路径和版本） |
| ARTIFACT_003 | 仓库不存在 |
| ARTIFACT_004 | 制品正在被引用，无法删除 |
| ARTIFACT_005 | 文件校验和不匹配 |
| ARTIFACT_006 | 文件上传失败 |
| ARTIFACT_007 | 存储空间不足 |
| ARTIFACT_008 | 版本格式不正确 |

## 注意事项

1. **文件存储**: 实际制品文件存储在Blob Store中，数据库只存储元数据
2. **下载统计**: 每次下载需记录到download_log表，并更新制品的downloads计数
3. **版本管理**: 同一制品的不同版本作为独立记录存储，通过path关联
4. **星标功能**: 星标数据存储在独立的artifact_star表中，支持用户级星标
5. **漏洞信息**: 漏洞数据来自安全扫描模块，异步更新到artifact表的vulnerability字段
6. **多租户隔离**: 所有查询自动按租户ID过滤
7. **权限控制**: 下载和查看权限可能受仓库访问控制影响
