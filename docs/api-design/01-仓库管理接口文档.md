# 仓库管理接口文档

## 概述
本文档定义了制品仓库管理相关的RESTful API接口，包括仓库的增删改查、状态管理、统计查询等功能。

---

## 1. 创建仓库

### 接口信息
- **接口路径**: `POST /api/v1/repositories`
- **接口描述**: 创建新的制品仓库
- **权限要求**: `REPOSITORY_CREATE`

### 请求参数

#### RepositoryCreateDto
```java
public class RepositoryCreateDto {
    @NotBlank
    private String name;                    // 仓库名称（唯一）
    
    @NotNull
    private RepositoryFormat format;        // 仓库格式
    
    @NotNull
    private RepositoryType type;            // 仓库类型
    
    @NotBlank
    private String description;             // 仓库描述
    
    private String remoteUrl;               // 远程仓库地址（proxy类型必填）
    
    private List<String> members;           // 成员仓库ID列表（group类型必填）
    
    @NotNull
    private RepositorySettingsDto settings; // 仓库设置
    
    private String blobStore;               // Blob存储名称
}
```

#### RepositorySettingsDto
```java
public class RepositorySettingsDto {
    @NotNull
    private Boolean isPublic;              // 是否公开
    
    @NotNull
    private Boolean indexed;               // 是否索引
    
    private Boolean cachingEnabled;        // 是否启用缓存（proxy类型）
    
    @NotNull
    private Boolean compressionEnabled;    // 是否启用压缩
}
```

## 6. 查询仓库列表

### 接口信息
- **接口路径**: `GET /api/v1/repositories`
- **接口描述**: 分页查询仓库列表，支持多维度筛选和搜索
- **权限要求**: `REPOSITORY_VIEW`

### 请求参数

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| page | Integer | 否 | 页码（从1开始） | 1 |
| size | Integer | 否 | 每页大小 | 10 |
| search | String | 否 | 搜索关键词（仓库名称、描述） | - |
| format | RepositoryFormat | 否 | 仓库格式筛选 | - |
| type | RepositoryType | 否 | 仓库类型筛选 | - |
| status | RepositoryStatus | 否 | 仓库状态筛选 | - |
| sort | String | 否 | 排序字段 | createdDate |
| order | String | 否 | 排序方向（asc/desc） | desc |

### 请求示例
```
GET /api/v1/repositories?page=1&size=10&format=MAVEN&type=HOSTED&status=ONLINE&sort=name&order=asc
```

### 响应参数

```java
public class PageResponse<T> {
```

## 数据库表设计建议

### repository 表
```sql
CREATE TABLE repository (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    name VARCHAR(255) NOT NULL,
    format VARCHAR(50) NOT NULL,
    type VARCHAR(50) NOT NULL,
    description TEXT,
    artifacts INT DEFAULT 0,
    size_bytes BIGINT DEFAULT 0,
    url VARCHAR(500),
    status VARCHAR(50) DEFAULT 'ONLINE',
    remote_url VARCHAR(500),
    blob_store VARCHAR(255),
    
    -- JSON字段（JPA使用对象映射）
    members JSON,              -- List<String>
    health JSON,               -- RepositoryHealthVo
    stats JSON,                -- RepositoryStatsVo
    security JSON,             -- RepositorySecurityVo
    settings JSON,             -- RepositorySettingsVo
    
    -- 审计字段
    created_by VARCHAR(64) NOT NULL,
    created_date TIMESTAMP NOT NULL,
    modified_by VARCHAR(64) NOT NULL,
    modified_date TIMESTAMP NOT NULL,
    
    last_updated TIMESTAMP,
    
    UNIQUE KEY uk_tenant_name (tenant_id, name),
    INDEX idx_tenant_format (tenant_id, format),
    INDEX idx_tenant_type (tenant_id, type),
    INDEX idx_tenant_status (tenant_id, status),
    INDEX idx_created_date (created_date)
);
```

## 错误码定义

| 错误码 | 说明 |
|--------|------|
| REPO_001 | 仓库名称已存在 |
| REPO_002 | 仓库不存在 |
| REPO_003 | 仓库类型不支持该操作 |
| REPO_004 | 仓库正在使用中，无法删除 |
| REPO_005 | Proxy类型仓库必须指定remoteUrl |
| REPO_006 | Group类型仓库必须指定members |
| REPO_007 | 仓库成员不存在 |
| REPO_008 | 仓库格式不匹配 |

## 注意事项

1. **枚举值处理**: 所有枚举类型已定义为Java枚举类，前端传递枚举名称（如"MAVEN"），后端自动映射
2. **JSON字段**: 使用JPA的JSON映射功能，直接将Java对象映射到数据库JSON字段，无需手动序列化
3. **审计字段**: 所有实体均包含租户ID、创建人、创建时间、修改人、修改时间
4. **分页响应**: 统一使用PageResponse结构，包含total和list
5. **删除操作**: 返回204状态码，响应体为空
6. **创建/更新操作**: 返回完整的实体对象
7. **校验注解**: 使用标准的Bean Validation注解，不添加message属性
8. **多租户**: 所有查询自动过滤租户ID，创建时自动填充租户ID
