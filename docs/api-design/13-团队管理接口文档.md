# 团队管理接口文档

## 概述
本文档定义了团队管理相关的RESTful API接口，包括成员管理、邀请管理、角色管理等功能。

---

## 1. 创建团队成员（邀请用户）

### 接口信息
- **接口路径**: `POST /api/v1/team/members/invite`
- **接口描述**: 邀请新用户加入团队
- **权限要求**: `TEAM_INVITE`

### 请求参数

#### MemberInviteDto
```java
public class MemberInviteDto {
    @NotBlank
    @Email
    private String email;
    
    @NotNull
    private UserRole role;              // OWNER/ADMIN/DEVELOPER/VIEWER
    
    private String message;             // 邀请消息（可选）
}
```

#### UserRole（枚举）
```java
public enum UserRole {
    OWNER("owner"),
    ADMIN("admin"),
    DEVELOPER("developer"),
    VIEWER("viewer");
    
    private final String value;
}
```

### 请求示例
```json
{
  "email": "alex.wilson@company.com",
  "role": "DEVELOPER",
  "message": "Welcome to join our team!"
}
```

### 响应参数

#### TeamInvitationVo
```java
public class TeamInvitationVo {
    private String tenantId;
    private String createdBy;
    private String creator;
    private LocalDateTime createdDate;
    
    private String id;
    private String email;
    private UserRole role;
    private String invitedBy;
    private String invitedByName;
    private LocalDateTime invitedDate;
    private String expiresIn;           // 相对时间
    private LocalDateTime expiresAt;
    private InvitationStatus status;
}
```

#### InvitationStatus（枚举）
```java
public enum InvitationStatus {
    PENDING("pending"),
    ACCEPTED("accepted"),
    DECLINED("declined"),
    EXPIRED("expired");
    
    private final String value;
}
```

### 响应示例
```json
{
  "code": "S",
  "message": "成功",
  "data": {
    "tenantId": "1",
    "createdBy": "1000001",
    "creator": "John Anderson",
    "createdDate": "2025-01-19T14:30:00",
    "id": "invite_1234567890",
    "email": "alex.wilson@company.com",
    "role": "DEVELOPER",
    "invitedBy": "1000001",
    "invitedByName": "John Anderson",
    "invitedDate": "2025-01-19T14:30:00",
    "expiresIn": "7 days",
    "expiresAt": "2025-01-26T14:30:00",
    "status": "PENDING"
  },
  "timestamp": "1737270600000"
}
```

- **接口描述**: 更新团队成员的角色
- **权限要求**: `TEAM_MANAGE`

### 路径参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 成员ID |

### 请求参数

#### MemberRoleUpdateDto
```java
public class MemberRoleUpdateDto {
    @NotNull
    private UserRole role;
}
```

### 请求示例
```json
{
  "role": "ADMIN"
}
```

### 响应参数
返回完整的 `TeamMemberVo` 对象

## 5. 查询团队成员列表

### 接口信息
- **接口路径**: `GET /api/v1/team/members`
- **接口描述**: 分页查询团队成员列表
- **权限要求**: `TEAM_VIEW`

### 请求参数

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| page | Integer | 否 | 页码 | 1 |
| size | Integer | 否 | 每页大小 | 10 |
| search | String | 否 | 搜索关键词（姓名、邮箱） | - |
| role | UserRole | 否 | 角色筛选 | - |
| status | MemberStatus | 否 | 状态筛选 | - |

### 响应参数
分页响应结构（PageResponse<TeamMemberVo>）

## 10. 接受邀请（公开接口）

### 接口信息
- **接口路径**: `POST /api/v1/public/invitations/{token}/accept`
- **接口描述**: 通过邀请token接受邀请
- **权限要求**: 无（公开接口）

### 路径参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| token | String | 是 | 邀请Token |

### 请求参数

#### InvitationAcceptDto
```java
public class InvitationAcceptDto {
    @NotBlank
    private String name;
    
    @NotBlank
    @Size(min = 8)
    private String password;
}
```

### 响应参数

#### InvitationAcceptResultVo
```java
public class InvitationAcceptResultVo {
    private Boolean success;
    private String userId;
    private String accessToken;
```

## 数据库表设计

### team_member 表
```sql
CREATE TABLE team_member (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    user_id VARCHAR(64) NOT NULL,
    name VARCHAR(255) NOT NULL,
    email VARCHAR(255) NOT NULL,
    avatar VARCHAR(500),
    role VARCHAR(50) NOT NULL,
    status VARCHAR(50) DEFAULT 'ACTIVE',
    joined_date TIMESTAMP NOT NULL,
    last_active TIMESTAMP,
    
    created_date TIMESTAMP NOT NULL,
    
    UNIQUE KEY uk_tenant_user (tenant_id, user_id),
    INDEX idx_tenant_role (tenant_id, role),
    INDEX idx_email (email)
);
```

### team_invitation 表
```sql
CREATE TABLE team_invitation (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    email VARCHAR(255) NOT NULL,
    role VARCHAR(50) NOT NULL,
    token VARCHAR(255) NOT NULL,
    status VARCHAR(50) DEFAULT 'PENDING',
    message TEXT,
    invited_by VARCHAR(64) NOT NULL,
    invited_date TIMESTAMP NOT NULL,
    expires_at TIMESTAMP NOT NULL,
    accepted_date TIMESTAMP,
    
    created_by VARCHAR(64) NOT NULL,
    created_date TIMESTAMP NOT NULL,
    
    UNIQUE KEY uk_token (token),
    INDEX idx_tenant_email (tenant_id, email),
    INDEX idx_status (status),
    INDEX idx_expires (expires_at)
);
```

## 错误码

| 错误码 | 说明 |
|--------|------|
| TEAM_001 | 成员不存在 |
| TEAM_002 | 邀请不存在或已过期 |
| TEAM_003 | 邮箱已被邀请 |
| TEAM_004 | 用户已是团队成员 |
| TEAM_005 | 无法删除自己 |
| TEAM_006 | 无法删除OWNER |
| TEAM_007 | 邀请已被接受或拒绝 |

## 注意事项

1. **邀请过期**: 邀请默认7天过期
2. **邮件发送**: 邀请创建后自动发送邀请邮件
3. **权限继承**: 新成员根据角色自动获得相应权限
4. **OWNER限制**: 每个租户至少保留一个OWNER
5. **自动激活**: 接受邀请后用户状态自动为ACTIVE
