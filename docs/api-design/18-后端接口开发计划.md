## 1. 开发计划总览

### 1.1 计划说明

本开发计划覆盖 AngusRepo 制品仓库管理系统全部 **15个功能模块**、**113+ 接口**的完整后端开发任务。计划按照 **模块依赖关系** 进行优先级排序，确保基础依赖接口优先实现，上层业务接口建立在稳定基础之上。

### 1.2 开发原则

1. **依赖优先**：基础模块（仓库、用户、系统）优先实现，上层模块依赖基础模块
2. **DDD分层**：严格遵循 接口层 → 应用层 → 领域层 → 基础设施层 的分层架构
3. **规范一致**：所有模块统一遵循《00-接口开发规范-完整版.md》的编码规范
4. **渐进交付**：按阶段交付，每阶段可独立测试和部署

## 10. 风险与注意事项

### 10.1 技术风险

| 风险项 | 影响 | 缓解措施 |
|--------|------|----------|
| 多租户数据隔离 | 数据泄露 | 所有查询自动添加 tenant_id 过滤，使用 `@MultiTenant` 注解 |
| 文件上传性能 | 大文件上传慢 | 支持分片上传、异步处理 |
| 统计查询性能 | 数据量大时查询慢 | 使用缓存（Redis TTL: 5~30分钟）、统计快照表 |
| 全文搜索性能 | 数据量大时搜索慢 | 使用搜索仓储（Elasticsearch 可选） |

### 10.2 关键注意事项

1. **所有实体必须包含审计字段**（tenantId、createdBy、createdDate、modifiedBy、modifiedDate）
2. **所有查询自动添加 tenant_id 过滤**，确保多租户隔离
3. **PUT接口使用替换覆盖语义**，不是部分更新
4. **DELETE接口返回 204 状态码**，响应体为空
5. **POST接口返回 201 状态码**
6. **Bean Validation 注解不添加 message 属性**
7. **门面层调用的 Cmd/Query 方法必须添加 `BizTemplate`**
8. **异常信息使用参数占位符**：`ResourceNotFound.of("资源「{0}」不存在", new Object[]{id})`
9. **Swagger注解不可遗漏**：`@Tag`、`@Operation`、`@Schema`、`@ApiResponses`
10. **MySQL和PostgreSQL实现都需要创建**
