# 趋势分析接口文档

## 概述
本文档定义了趋势分析相关的RESTful API接口，包括热门制品、热门仓库、下载趋势、上传趋势等功能。

---

## 1. 查询热门制品排行

### 接口信息
- **接口路径**: `GET /api/v1/analytics/trending-artifacts`
- **接口描述**: 查询热门制品排行榜
- **权限要求**: `ANALYTICS_VIEW`

### 请求参数

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| page | Integer | 否 | 页码 | 1 |
| size | Integer | 否 | 每页大小 | 10 |
| timeRange | String | 否 | 时间范围（today/thisWeek/thisMonth/thisYear） | thisWeek |
| format | ArtifactFormat | 否 | 格式筛选 | - |
| repository | String | 否 | 仓库筛选 | - |
| search | String | 否 | 搜索关键词 | - |

### 响应参数

#### TrendingArtifactVo
```java
public class TrendingArtifactVo {
    private String tenantId;
    private LocalDateTime createdDate;
    
    private String id;
    private Integer rank;               // 排名
    private String name;
    private String groupId;
    private String version;
    private String repository;
    private String format;
    private Long downloads;             // 总下载量
    private Long weeklyDownloads;       // 周下载量
    private Double growth;              // 增长率
    private String trend;               // up/down/stable
    private Integer uniqueUsers;        // 唯一用户数
    private Integer stars;              // 星标数
    private String lastUpdated;
}
```

## 数据库表设计

趋势分析主要通过聚合查询和统计表实现：

### artifact_download_stats 表（聚合统计表）
```sql
CREATE TABLE artifact_download_stats (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    artifact_id VARCHAR(64) NOT NULL,
    date DATE NOT NULL,
    download_count BIGINT DEFAULT 0,
    unique_users INT DEFAULT 0,
    
    created_date TIMESTAMP NOT NULL,
    
    UNIQUE KEY uk_artifact_date (artifact_id, date),
    INDEX idx_tenant_date (tenant_id, date DESC),
    
    FOREIGN KEY (artifact_id) REFERENCES artifact(id) ON DELETE CASCADE
);
```

### repository_stats_daily 表
```sql
CREATE TABLE repository_stats_daily (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    repository_id VARCHAR(64) NOT NULL,
    date DATE NOT NULL,
    downloads BIGINT DEFAULT 0,
    uploads BIGINT DEFAULT 0,
    storage_bytes BIGINT DEFAULT 0,
    unique_users INT DEFAULT 0,
    
    created_date TIMESTAMP NOT NULL,
    
    UNIQUE KEY uk_repo_date (repository_id, date),
    INDEX idx_tenant_date (tenant_id, date DESC),
    
    FOREIGN KEY (repository_id) REFERENCES repository(id) ON DELETE CASCADE
);
```

## 注意事项

1. **数据聚合**: 趋势数据需要通过定时任务每日聚合
2. **缓存策略**: 历史趋势数据缓存时间可以较长（1小时）
3. **性能优化**: 使用聚合表避免实时查询大量数据
4. **时间粒度**: 
   - 7天内：按天
   - 30天内：按天
   - 90天内：按周
   - 1年：按月
