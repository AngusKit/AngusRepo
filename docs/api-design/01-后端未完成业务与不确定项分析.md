## 4. 不确定如何处理的业务项

### 4.1 ActivityLogCmdImpl.create() — null 输入处理策略

**文件路径**：`application/cmd/activitylog/impl/ActivityLogCmdImpl.java`

```java
public ActivityLog create(ActivityLog activityLog) {
    if (Objects.isNull(activityLog)) {
        return null;  // 返回 null 而非抛异常
    }
    // ...
}
```

**不确定点**：按照规范，应该抛出 `ProtocolException` 或 `IllegalArgumentException`，但此方法可能被内部批量调用，返回 null 可能是有意设计。  
**建议**：确认调用方是否处理了 null 返回值。若为外部门面层调用，应改为抛异常；若为内部批量处理，保持 null 返回但在调用方做防御。

### 4.3 PyPIFormatHandler.extractPythonVersionFromWheel() — null 返回处理

private String extractPythonVersionFromWheel(String fileName) {
    String[] parts = fileName.replace(".whl", "").split("-");

### 4.4 ArtifactRest.removeStar() — DELETE 方法有返回值

**文件路径**：`interfaces/artifact/ArtifactRest.java`

```java
@DeleteMapping("/{id}/star")
public ApiLocaleResult<?> removeStar(@PathVariable Long id) {
    // ...
    return ApiLocaleResult.success();
}
```

**不确定点**：规范要求 DELETE 操作返回 `void` + HTTP 204。但「取消收藏」是语义上的 DELETE（删除收藏关系），而非资源删除。  
**建议**：两种方案均可接受：
- 方案 A：改为 `void` + 204（严格遵守规范）- 按方案A处理
- 方案 B：保持返回 200 + 空数据（语义更清晰，表示操作成功）

### 4.5 @Size 大值（500/1000/2000/4000）缺少 BizConstant

规范要求所有 `@Size(max=)` 使用 `BizConstant` 常量，但以下值没有对应常量：

| 当前值 | 涉及文件数 | 使用场景 | 建议新增常量 |
|--------|-----------|---------|-------------|
| 500 | 5 | description/url/path 字段 | `MAX_LONG_DESC_LENGTH = 500` |
| 1000 | 4 | 规则表达式/大段描述 | `MAX_EXPRESSION_LENGTH = 1000` |
| 2000 | 8 | 详细描述/webhook url | `MAX_CONTENT_LENGTH = 2000` |
| 4000 | 1 | 大文本元数据 | `MAX_METADATA_LENGTH = 4000` |

**建议**：在domain目录中 `Constants类` 中新增上述常量，然后替换 DTO 中的硬编码值。

### 4.6 格式协议层（Protocol）REST 控制器的规范适用性

10 个格式协议 REST 控制器（MavenProtocolRest、DockerProtocolRest 等）实现的是原生包管理器协议（如 Maven Deploy、Docker Registry API），不是标准的 CRUD REST API。

**不确定点**：
- 这些协议端点的 URL 路径遵循各包管理器规范（如 `/v2/` for Docker），不遵循 `/api/v1/` 规范
- HTTP 方法和状态码遵循各协议规范，不遵循通用 REST 规范
- 响应格式不使用 `ApiLocaleResult<T>` 包装

**建议**：这些协议层控制器HTTP 方法和状态码遵循各协议规范，不遵循通用 REST 规范，但仍需添加 `@Parameter` 注解以支持 API 文档生成。
