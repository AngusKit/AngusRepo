# 用户个人设置接口文档

## 概述
本文档定义了用户个人设置相关的RESTful API接口，包括个人信息管理、密码修改、通知偏好、API Token管理等功能。

## 7. 创建API Token

### 接口信息
- **接口路径**: `POST /api/v1/users/api-tokens`
- **接口描述**: 创建个人API Token
- **权限要求**: 已认证用户

### 请求参数

#### ApiTokenCreateDto
```java
public class ApiTokenCreateDto {
    @NotBlank
    private String name;
    
    private String description;
    
    @NotNull
    private TokenPermission permission;     // READ/WRITE/ADMIN
    
    private LocalDateTime expiresAt;        // 过期时间（可选）
}
```

#### TokenPermission（枚举）
```java
public enum TokenPermission {
    READ("read"),
    WRITE("write"),
    ADMIN("admin");
    
    private final String value;
}
```

### 请求示例
```json
{
  "name": "CI/CD Pipeline",
  "description": "Token for Jenkins CI/CD",
  "permission": "WRITE",
  "expiresAt": "2025-12-31T23:59:59"
}
```

### 响应参数

#### ApiTokenVo
```java
public class ApiTokenVo {
    private String id;
    private String name;
    private String description;
    private String token;               // 明文token（仅创建时返回）
    private String tokenHash;           // token哈希
    private TokenPermission permission;
    private Boolean enabled;
    private LocalDateTime expiresAt;
    private LocalDateTime created;
    private LocalDateTime lastUsed;
    private Long usageCount;
}
```

### 响应示例
```json
{
  "code": "S",
  "message": "成功",
  "data": {
```

## 数据库表设计

### user_profile 表
```sql
CREATE TABLE user_profile (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    name VARCHAR(255) NOT NULL,
    email VARCHAR(255) NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    avatar VARCHAR(500),
    role VARCHAR(50),
    department VARCHAR(255),
    joined_date TIMESTAMP NOT NULL,
    last_login TIMESTAMP,
    
    -- JSON字段
    preferences JSON,
    notification_settings JSON,
    
    created_date TIMESTAMP NOT NULL,
    modified_date TIMESTAMP NOT NULL,
    
    UNIQUE KEY uk_tenant_email (tenant_id, email),
    INDEX idx_email (email)
);
```

### user_api_token 表
```sql
CREATE TABLE user_api_token (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    user_id VARCHAR(64) NOT NULL,
    name VARCHAR(255) NOT NULL,
    description TEXT,
    token_hash VARCHAR(255) NOT NULL,
    permission VARCHAR(50) NOT NULL,
    enabled BOOLEAN DEFAULT TRUE,
    expires_at TIMESTAMP,
    last_used TIMESTAMP,
    usage_count BIGINT DEFAULT 0,
    
    created_date TIMESTAMP NOT NULL,
    
    UNIQUE KEY uk_token_hash (token_hash),
    INDEX idx_user (user_id),
    
    FOREIGN KEY (user_id) REFERENCES user_profile(id) ON DELETE CASCADE
);
```

## 错误码

| 错误码 | 说明 |
|--------|------|
| USER_001 | 用户不存在 |
| USER_002 | 原密码错误 |
| USER_003 | 新密码不符合要求 |
| USER_004 | 两次输入的密码不一致 |
| USER_005 | Token名称已存在 |
| USER_006 | Token不存在 |
| USER_007 | 头像文件太大 |
| USER_008 | 头像格式不支持 |

## 注意事项

1. **Token安全**: Token明文仅在创建时返回一次，需要用户妥善保管
2. **密码策略**: 新密码必须符合系统密码策略要求
3. **头像存储**: 头像文件存储在CDN，返回完整URL
4. **Token过期**: 过期Token自动失效，定期清理
5. **偏好同步**: 偏好设置变更实时生效
