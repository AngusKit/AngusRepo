# 制品上传接口文档

## 概述
本文档定义了制品上传相关的RESTful API接口，包括单文件上传、分片上传、批量上传等功能。

---

## 1. 创建上传任务

### 接口信息
- **接口路径**: `POST /api/v1/uploads`
- **接口描述**: 创建制品上传任务（获取上传凭证和URL）
- **权限要求**: `ARTIFACT_UPLOAD`

### 请求参数

#### UploadTaskCreateDto
```java
public class UploadTaskCreateDto {
    @NotBlank
    private String repositoryId;        // 目标仓库ID
    
    @NotBlank
    private String fileName;            // 文件名
    
    @NotNull
    private Long fileSize;              // 文件大小（字节）
    
    @NotBlank
    private String checksum;            // 文件MD5/SHA256校验和
    
    private String path;                // 上传路径（可选）
    
    private String version;             // 版本号（可选）
    
    private Boolean enableChunked;      // 是否启用分片上传
    
    private Integer chunkSize;          // 分片大小（字节，默认5MB）
}
```

### 请求示例
```json
{
  "repositoryId": "1",
  "fileName": "spring-core-6.1.0.jar",
  "fileSize": 1572864,
  "checksum": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
  "path": "org/springframework/spring-core",
  "version": "6.1.0",
  "enableChunked": false
}
```

### 响应参数

## 2. 上传文件

### 接口信息
- **接口路径**: `POST /api/v1/uploads/{taskId}/file`
- **接口描述**: 上传制品文件（单文件或分片）
- **权限要求**: 需要有效的上传令牌
- **Content-Type**: multipart/form-data

### 路径参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| taskId | String | 是 | 上传任务ID |

### 请求参数

#### Form Data
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | File | 是 | 文件数据 |
| chunkIndex | Integer | 否 | 分片索引（从0开始） |
| chunkChecksum | String | 否 | 分片校验和 |

### 请求头
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | String | 是 | Bearer {uploadToken} |

### 响应参数
返回更新后的 `UploadTaskVo` 对象

## 3. 完成上传

### 接口信息
- **接口路径**: `PUT /api/v1/uploads/{taskId}/complete`
- **接口描述**: 标记上传完成，触发后续处理
- **权限要求**: `ARTIFACT_UPLOAD`

### 路径参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| taskId | String | 是 | 上传任务ID |

### 请求参数

#### UploadCompleteDto
```java
public class UploadCompleteDto {
    private String description;          // 制品描述
    private String license;              // 许可证
    private List<String> tags;           // 标签
    private ArtifactMetadataDto metadata; // 元数据
}
```

### 请求示例
```json
{
  "description": "Spring Core Framework",
  "license": "Apache-2.0",
  "tags": ["framework", "spring"],
  "metadata": {
    "groupId": "org.springframework",
    "artifactId": "spring-core",
    "packaging": "jar"
  }
}
```

### 响应参数
返回创建的 `ArtifactVo` 对象（参考制品管理接口）

## 4. 取消上传

### 接口信息
- **接口路径**: `PUT /api/v1/uploads/{taskId}/cancel`
- **接口描述**: 取消上传任务并清理临时文件
- **权限要求**: `ARTIFACT_UPLOAD`

### 路径参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| taskId | String | 是 | 上传任务ID |

### 请求参数
无

### 响应参数
返回更新后的 `UploadTaskVo` 对象（status为CANCELLED）

## 6. 查询上传任务列表

### 接口信息
- **接口路径**: `GET /api/v1/uploads`
- **接口描述**: 查询当前用户的上传任务列表
- **权限要求**: `ARTIFACT_UPLOAD`

## 数据库表设计建议

### upload_task 表
```sql
CREATE TABLE upload_task (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    repository_id VARCHAR(64) NOT NULL,
    file_name VARCHAR(500) NOT NULL,
    file_size BIGINT NOT NULL,
    checksum VARCHAR(255) NOT NULL,
    path VARCHAR(1000),
    version VARCHAR(100),
    status VARCHAR(50) DEFAULT 'PENDING',
    upload_token VARCHAR(1000),
    expires TIMESTAMP,
    enable_chunked BOOLEAN DEFAULT FALSE,
    total_chunks INT DEFAULT 0,
    uploaded_chunks INT DEFAULT 0,
    progress INT DEFAULT 0,
    artifact_id VARCHAR(64),       -- 关联的制品ID（完成后填充）
    error_message TEXT,
    
    created_by VARCHAR(64) NOT NULL,
    created_date TIMESTAMP NOT NULL,
    
    INDEX idx_tenant_status (tenant_id, status),
    INDEX idx_created_by (created_by),
    INDEX idx_created_date (created_date DESC),
    
    FOREIGN KEY (repository_id) REFERENCES repository(id) ON DELETE CASCADE
);
```

### upload_chunk 表（分片上传）
```sql
CREATE TABLE upload_chunk (
    id VARCHAR(64) PRIMARY KEY,
    upload_task_id VARCHAR(64) NOT NULL,
    chunk_index INT NOT NULL,
    chunk_size BIGINT NOT NULL,
    checksum VARCHAR(255),
    uploaded_date TIMESTAMP,
    
    UNIQUE KEY uk_task_index (upload_task_id, chunk_index),
    
    FOREIGN KEY (upload_task_id) REFERENCES upload_task(id) ON DELETE CASCADE
);
```

## 错误码定义

| 错误码 | 说明 |
|--------|------|
| UPLOAD_001 | 上传任务不存在 |
| UPLOAD_002 | 上传令牌无效或已过期 |
| UPLOAD_003 | 文件校验和不匹配 |
| UPLOAD_004 | 文件大小超过限制 |
| UPLOAD_005 | 仓库不支持上传 |
| UPLOAD_006 | 存储空间不足 |
| UPLOAD_007 | 分片索引无效 |
| UPLOAD_008 | 上传任务已完成或已取消 |

## 注意事项

1. **令牌安全**: 上传令牌应设置合理的过期时间（建议1小时）
2. **分片上传**: 大文件（>100MB）建议使用分片上传
3. **校验和验证**: 上传完成后必须验证文件完整性
4. **临时存储**: 上传中的文件存储在临时目录，完成后移动到正式存储
5. **并发上传**: 支持多个文件同时上传
6. **重复检测**: 根据checksum检测是否已存在相同文件，避免重复上传
7. **权限检查**: 上传前检查仓库是否允许上传（hosted类型）
