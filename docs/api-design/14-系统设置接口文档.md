# 系统设置接口文档

## 概述
本文档定义了系统设置相关的RESTful API接口，包括通用配置、存储配置、认证配置、集成配置等功能。

---

## 1. 查询系统配置

### 接口信息
- **接口路径**: `GET /api/v1/system/settings`
- **接口描述**: 查询系统全局配置
- **权限要求**: `SYSTEM_SETTINGS_VIEW`

### 请求参数
无

### 响应参数

#### SystemSettingsVo
```java
public class SystemSettingsVo {
    private GeneralSettingsVo general;
    private StorageSettingsVo storage;
    private AuthSettingsVo authentication;
    private IntegrationSettingsVo integrations;
    private SecuritySettingsVo security;
}
```

#### GeneralSettingsVo
```java
public class GeneralSettingsVo {
    private String systemName;
    private String systemUrl;
    private Boolean maintenanceMode;
    private Boolean debugMode;
    private String adminEmail;
}
```

#### StorageSettingsVo
```java
public class StorageSettingsVo {
    private StorageBackend backend;     // LOCAL/S3/AZURE/GCS
    private S3ConfigVo s3Config;
    private Boolean backupEnabled;
    private String backupSchedule;      // cron表达式
    private String backupRetentionDays;
}
```

**StorageBackend（枚举）**
```java
public enum StorageBackend {
    LOCAL("local"),
    S3("s3"),
    AZURE("azure"),
    GCS("gcs");
    
    private final String value;
}
```

#### S3ConfigVo
```java
public class S3ConfigVo {
    private String bucket;
    private String region;
    private String accessKey;           // 脱敏显示
    private String endpoint;            // 自定义endpoint（可选）
}
```

#### AuthSettingsVo
```java
public class AuthSettingsVo {
    private Boolean ldapEnabled;
    private LdapConfigVo ldapConfig;
    private Boolean samlEnabled;
    private SamlConfigVo samlConfig;
    private Boolean oauth2Enabled;
    private PasswordPolicyVo passwordPolicy;
}
```

#### LdapConfigVo
```java

    private String server;

    private String baseDn;

```

#### SamlConfigVo
```java

```

#### PasswordPolicyVo
```java

    private Integer minLength;
    private Boolean requireUppercase;

    private Boolean requireSymbols;
    private Integer expiryDays;

```

#### IntegrationSettingsVo
```java
public class IntegrationSettingsVo {
    private Boolean jenkinsEnabled;
    private Boolean gitlabEnabled;
    private Boolean jiraEnabled;
    private Boolean slackEnabled;
    private SlackConfigVo slackConfig;

```

#### SlackConfigVo
```java

```

#### SecuritySettingsVo
```java

    private Boolean forceTwoFactor;
    private Boolean allowApiAccess;
    private Integer sessionTimeout;     // 分钟
    private List<String> ipWhitelist;
}
```

## 6. 测试连接

### 接口信息
- **接口路径**: `POST /api/v1/system/settings/test-connection`
- **接口描述**: 测试外部服务连接
- **权限要求**: `SYSTEM_SETTINGS_VIEW`

### 请求参数

#### ConnectionTestDto
```java
public class ConnectionTestDto {
    @NotNull
    private ConnectionType type;        // LDAP/SAML/S3/SLACK等
    
    private Map<String, String> config; // 配置参数
}
```

**ConnectionType（枚举）**
```java
public enum ConnectionType {
    LDAP("ldap"),
    SAML("saml"),
    S3("s3"),
    SLACK("slack"),
    SMTP("smtp");
    
    private final String value;
}
```

### 响应参数

#### ConnectionTestResultVo
```java
public class ConnectionTestResultVo {
    private Boolean success;
    private String message;
    private Long responseTime;          // 响应时间（毫秒）
}
```

### 响应示例
```json
{
  "code": "S",
  "message": "成功",
  "data": {
    "success": true,
    "message": "LDAP连接测试成功",
    "responseTime": 125
  },
  "timestamp": "1737270600000"
}
```

## 数据库表设计

### system_settings 表
```sql
CREATE TABLE system_settings (
    id VARCHAR(64) PRIMARY KEY,
    setting_key VARCHAR(255) NOT NULL,
    setting_value TEXT,
    value_type VARCHAR(50),     -- STRING/NUMBER/BOOLEAN/JSON
    encrypted BOOLEAN DEFAULT FALSE,
    
    modified_by VARCHAR(64),
    modified_date TIMESTAMP,
    
    UNIQUE KEY uk_setting_key (setting_key)
);
```

### system_license 表
```sql
CREATE TABLE system_license (
    id VARCHAR(64) PRIMARY KEY,
    license_type VARCHAR(50) NOT NULL,
    license_key TEXT NOT NULL,
    license_to VARCHAR(255),
    issued_date TIMESTAMP,
    expires_at TIMESTAMP,
    max_users INT,
    max_repositories INT,
    max_storage BIGINT,
    
    -- JSON字段
    features JSON,
    
    created_date TIMESTAMP NOT NULL,
    modified_date TIMESTAMP NOT NULL
);
```

## 注意事项

1. **敏感信息**: 密钥等敏感信息需要加密存储，返回时脱敏
2. **权限控制**: 系统设置需要最高权限
3. **配置验证**: 更新配置前需验证有效性
4. **维护模式**: 进入维护模式会拒绝非管理员访问
5. **热更新**: 部分配置支持热更新，无需重启
