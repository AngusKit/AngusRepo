# 分析统计接口文档

## 概述
本文档定义了Analytics分析统计相关的RESTful API接口，包括下载分析、用户分析、仓库分析、导出报告等功能。

---

## 1. 查询下载统计数据

### 接口信息
- **接口路径**: `GET /api/v1/analytics/downloads`
- **接口描述**: 查询下载统计分析数据
- **权限要求**: `ANALYTICS_VIEW`

### 请求参数

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| timeRange | String | 否 | 时间范围（7days/30days/90days） | 7days |
| repositoryId | String | 否 | 仓库ID筛选 | - |
| format | ArtifactFormat | 否 | 格式筛选 | - |

### 响应参数

#### DownloadAnalyticsVo
```java
public class DownloadAnalyticsVo {
    private List<DownloadChartDataVo> chartData;    // 图表数据
    private List<TopArtifactVo> topArtifacts;       // Top制品
    private DownloadSummaryVo summary;              // 汇总数据
}
```

#### DownloadChartDataVo
```java
public class DownloadChartDataVo {
    private String date;
    private Long downloads;
}
```

#### TopArtifactVo
```java
public class TopArtifactVo {
    private String name;
    private String repository;
    private Long downloads;
    private Double change;              // 变化百分比
}
```

#### DownloadSummaryVo
```java
public class DownloadSummaryVo {
    private Long totalDownloads;
    private Long averageDaily;
    private Double growthRate;
}
```

### 响应示例
```json
{
  "code": "S",
  "message": "成功",
  "data": {
    "chartData": [
      {
        "date": "01/12",
        "downloads": 1200
      }
    ],
    "topArtifacts": [
      {
        "name": "spring-core",
        "repository": "maven-releases",
        "downloads": 125430,
        "change": 12.0
      }
    ],
    "summary": {
      "totalDownloads": 12450,
      "averageDaily": 1778,
      "growthRate": 15.5
    }
  },
  "timestamp": "1737270600000"
}
```

## 2. 查询用户活跃度统计

### 接口信息
- **接口路径**: `GET /api/v1/analytics/user-activity`
- **接口描述**: 查询用户活跃度分析数据
- **权限要求**: `ANALYTICS_VIEW`

### 请求参数

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| timeRange | String | 否 | 时间范围 | 7days |

### 响应参数

#### UserActivityAnalyticsVo
```java
public class UserActivityAnalyticsVo {
    private List<TopUserVo> topUsers;           // Top用户
    private UserActivitySummaryVo summary;      // 汇总数据
}
```

#### TopUserVo
```java
public class TopUserVo {
    private String name;
    private Long downloads;
    private Integer uploads;
}
```

#### UserActivitySummaryVo
```java
public class UserActivitySummaryVo {
    private Integer totalUsers;
    private Integer activeUsers;
    private Integer newUsers;
    private Double activityRate;
}
```

## 3. 查询仓库对比分析

### 接口信息
- **接口路径**: `GET /api/v1/analytics/repository-comparison`
- **接口描述**: 查询仓库对比分析数据
- **权限要求**: `ANALYTICS_VIEW`

### 请求参数

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| repositoryIds | List<String> | 否 | 仓库ID列表（最多5个） | 全部 |

### 响应参数

#### RepositoryComparisonVo
```java
public class RepositoryComparisonVo {
    private List<RepositoryCompareItemVo> repositories;
}
```

#### RepositoryCompareItemVo
```java
public class RepositoryCompareItemVo {
    private String name;
    private String format;
    private String type;
    private Integer artifacts;
    private String size;
    private Long downloads;
}
```

## 4. 导出分析报告

### 接口信息
- **接口路径**: `GET /api/v1/analytics/export`
- **接口描述**: 导出分析报告（PDF/Excel）
- **权限要求**: `ANALYTICS_EXPORT`

### 请求参数

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| format | String | 否 | 导出格式（pdf/excel） | pdf |
| timeRange | String | 否 | 时间范围 | 30days |
| sections | List<String> | 否 | 报告章节（downloads/users/repos） | 全部 |

### 响应参数
- **Content-Type**: application/pdf 或 application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
- **Content-Disposition**: attachment; filename="analytics-report-20250119.pdf"
- **响应内容**: 文件流

## 5. 查询格式使用统计

### 接口信息
- **接口路径**: `GET /api/v1/analytics/format-usage`
- **接口描述**: 查询各格式的使用统计
- **权限要求**: `ANALYTICS_VIEW`

### 请求参数
无

### 响应参数

#### FormatUsageVo
```java
public class FormatUsageVo {
    private List<FormatUsageItemVo> formats;
}
```

#### FormatUsageItemVo
```java
public class FormatUsageItemVo {
    private String format;
    private Integer repositoryCount;
    private Long artifactCount;
    private String totalSize;
    private Long downloads;
    private Double percentage;          // 使用占比
}
```

## 数据库表设计

分析统计主要复用已有统计表和聚合表，不需要新增表。

## 错误码

| 错误码 | 说明 |
|--------|------|
| ANALYTICS_001 | 分析数据不存在 |
| ANALYTICS_002 | 导出失败 |
| ANALYTICS_003 | 时间范围无效 |

## 注意事项

1. **数据刷新**: 分析数据每小时刷新一次
2. **导出限制**: 报告导出有频率限制（每用户每天最多10次）
3. **大数据处理**: 导出大量数据时使用异步任务
4. **权限控制**: 不同角色看到的分析维度不同
