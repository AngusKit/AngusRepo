# 清理策略接口文档

## 概述
本文档定义了制品清理策略相关的RESTful API接口，包括策略的管理、执行、记录查询等功能。

---

## 1. 创建清理策略

### 接口信息
- **接口路径**: `POST /api/v1/cleanup-policies`
- **接口描述**: 创建清理策略
- **权限要求**: `CLEANUP_POLICY_CREATE`

### 请求参数

#### CleanupPolicyCreateDto
```java
public class CleanupPolicyCreateDto {
    @NotBlank
    private String name;
    
    private String description;
    
    @NotBlank
    private String repositoryId;
    
    @NotNull
    private CleanupType type;               // 清理类型
    
    @NotNull
    private CleanupCondition condition;     // 清理条件
    
    @NotNull
    private CleanupSchedule schedule;       // 调度配置
    
    @NotNull
    private Boolean enabled;
    
    private Boolean dryRun;                 // 是否试运行
}
```

#### 枚举定义

**CleanupType（清理类型）**
```java
public enum CleanupType {
    BY_AGE("by_age"),                // 按时间
    BY_COUNT("by_count"),            // 按数量
    BY_SIZE("by_size"),              // 按大小
    BY_PATTERN("by_pattern");        // 按模式
    
    private final String value;
}
```

#### CleanupCondition
```java
public class CleanupCondition {
    private Integer olderThanDays;          // 超过N天未使用
    private Integer keepLastVersions;       // 保留最新N个版本
    private Long maxSizeBytes;              // 最大存储字节
    private String namePattern;             // 名称匹配模式（正则）
    private Integer minDownloads;           // 最小下载次数
}
```

#### CleanupSchedule
```java
public class CleanupSchedule {
    private ScheduleType type;
    private String cronExpression;
}
```

### 请求示例
```json
{
  "name": "清理过期快照",
  "description": "删除30天未使用的SNAPSHOT版本",
  "repositoryId": "9",
  "type": "BY_AGE",
  "condition": {
    "olderThanDays": 30,
    "namePattern": ".*-SNAPSHOT"
  },
  "schedule": {
    "type": "DAILY",
    "cronExpression": "0 3 * * *"
  },
  "enabled": true,
  "dryRun": false
}
```

## 2. 更新清理策略
- **接口路径**: `PUT /api/v1/cleanup-policies/{id}`
- **请求参数**: 同创建策略
- **响应参数**: CleanupPolicyVo

---

## 3. 启用/禁用策略
- **接口路径**: `PUT /api/v1/cleanup-policies/{id}/enabled`
- **请求参数**: `{ "enabled": true/false }`
- **响应参数**: CleanupPolicyVo

---

## 4. 删除清理策略
- **接口路径**: `DELETE /api/v1/cleanup-policies/{id}`
- **响应**: 204 No Content

---

## 5. 查询策略详情
- **接口路径**: `GET /api/v1/cleanup-policies/{id}`
- **响应参数**: CleanupPolicyVo

---

## 6. 查询策略列表
- **接口路径**: `GET /api/v1/cleanup-policies`
- **请求参数**: page, size, repositoryId, enabled
- **响应**: PageResponse<CleanupPolicyVo>

---

## 7. 立即执行策略
- **接口路径**: `POST /api/v1/cleanup-policies/{id}/execute`
- **请求参数**: `{ "dryRun": true/false }`
- **响应参数**: CleanupExecutionVo

```java
public class CleanupExecutionVo {
    private String id;
    private String policyId;
    private String policyName;
    private CleanupStatus status;
    private Integer progress;
    private CleanupStatisticsVo statistics;
    private LocalDateTime startTime;
    private LocalDateTime endTime;
}
```

**CleanupStatus**
```java
public enum CleanupStatus {
    PENDING("pending"),
    RUNNING("running"),
    COMPLETED("completed"),
    FAILED("failed");
}
```

## 8. 查询执行历史
- **接口路径**: `GET /api/v1/cleanup-policies/{id}/executions`

## 数据库表设计

```sql
CREATE TABLE cleanup_policy (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    name VARCHAR(255) NOT NULL,
    description TEXT,
    repository_id VARCHAR(64) NOT NULL,
    type VARCHAR(50) NOT NULL,
    enabled BOOLEAN DEFAULT TRUE,
    dry_run BOOLEAN DEFAULT FALSE,
    last_executed TIMESTAMP,
    next_execution TIMESTAMP,
    execution_count INT DEFAULT 0,
    
    -- JSON字段
    condition JSON,
    schedule JSON,
    last_execution_stats JSON,
    
    created_by VARCHAR(64) NOT NULL,
    created_date TIMESTAMP NOT NULL,
    modified_by VARCHAR(64) NOT NULL,
    modified_date TIMESTAMP NOT NULL,
    
    INDEX idx_tenant_repository (tenant_id, repository_id),
    INDEX idx_next_execution (next_execution),
    
    FOREIGN KEY (repository_id) REFERENCES repository(id) ON DELETE CASCADE
);

CREATE TABLE cleanup_execution (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    policy_id VARCHAR(64) NOT NULL,
    status VARCHAR(50) DEFAULT 'PENDING',
    progress INT DEFAULT 0,
    start_time TIMESTAMP,
    end_time TIMESTAMP,
    
    -- JSON字段
    statistics JSON,
    
    created_date TIMESTAMP NOT NULL,
    
    INDEX idx_policy (policy_id),
    INDEX idx_start_time (start_time DESC),
    
    FOREIGN KEY (policy_id) REFERENCES cleanup_policy(id) ON DELETE CASCADE
);
```

## 注意事项

1. **试运行模式**: dryRun=true时只模拟执行，不实际删除
2. **定时任务**: 使用调度器定期执行已启用的策略
3. **批量删除**: 清理操作应分批执行，避免长时间锁表
4. **回滚机制**: 关键制品删除前应备份元数据
5. **通知告警**: 清理完成后发送通知
