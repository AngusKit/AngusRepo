# 通知管理接口文档

## 概述
本文档定义了系统通知管理相关的RESTful API接口，包括通知的创建、查询、标记、删除等功能。

---

## 1. 创建通知

### 接口信息
- **接口路径**: `POST /api/v1/notifications`
- **接口描述**: 创建系统通知（通常由系统自动触发）
- **权限要求**: `NOTIFICATION_CREATE`

### 请求参数

#### NotificationCreateDto
```java
public class NotificationCreateDto {
    @NotNull
    private NotificationType type;          // 通知类型
    
    @NotBlank
    private String title;                   // 通知标题
    
    @NotBlank
    private String description;             // 通知描述
    
    private NotificationPriority priority;  // 优先级
    
    private List<NotificationTagDto> tags;  // 标签列表
    
    private String relatedId;               // 关联对象ID
    
    private String relatedType;             // 关联对象类型
    
    private List<String> targetUsers;       // 目标用户列表（为空则发送给所有用户）
}
```

#### 枚举定义

**NotificationType（通知类型）**
```java
public enum NotificationType {
    SECURITY("security"),          // 安全告警
    STORAGE("storage"),            // 存储空间
    ACCESS("access"),              // 权限变更
    ARTIFACT("artifact"),          // 制品更新
    SYSTEM("system");              // 系统通知
    
    private final String value;
    
    NotificationType(String value) {
        this.value = value;
    }
}
```

**NotificationPriority（优先级）**
```java
public enum NotificationPriority {
    HIGH("high"),
    MEDIUM("medium"),
    LOW("low");
    
    private final String value;
    
    NotificationPriority(String value) {
        this.value = value;
    }
}
```

```java
public class NotificationTagDto {

## 6. 查询通知列表

### 接口信息
- **接口路径**: `GET /api/v1/notifications`
- **接口描述**: 分页查询当前用户的通知列表
- **权限要求**: `NOTIFICATION_VIEW`

### 请求参数

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| page | Integer | 否 | 页码 | 1 |
| size | Integer | 否 | 每页大小 | 10 |
| category | String | 否 | 分类筛选（all/unread/starred/archived） | all |
| type | NotificationType | 否 | 类型筛选 | - |
| priority | NotificationPriority | 否 | 优先级筛选 | - |
| search | String | 否 | 搜索关键词（标题、描述） | - |
| sort | String | 否 | 排序字段 | createdDate |
| order | String | 否 | 排序方向 | desc |

### 请求示例
```
GET /api/v1/notifications?page=1&size=10&category=unread&type=SECURITY&priority=HIGH

## 数据库表设计建议

### notification 表
```sql
CREATE TABLE notification (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    user_id VARCHAR(64) NOT NULL,
    type VARCHAR(50) NOT NULL,
    title VARCHAR(500) NOT NULL,
    description TEXT,
    priority VARCHAR(50),
    status VARCHAR(50) DEFAULT 'INFO',
    read_flag BOOLEAN DEFAULT FALSE,
    starred BOOLEAN DEFAULT FALSE,
    archived BOOLEAN DEFAULT FALSE,
    read_time TIMESTAMP,
    related_id VARCHAR(64),
    related_type VARCHAR(100),
    
    -- JSON字段
    tags JSON,                   -- List<NotificationTagVo>
    
    created_by VARCHAR(64) NOT NULL,
    created_date TIMESTAMP NOT NULL,
    modified_by VARCHAR(64) NOT NULL,
    modified_date TIMESTAMP NOT NULL,
    
    INDEX idx_tenant_user (tenant_id, user_id),
    INDEX idx_user_read (user_id, read_flag),
    INDEX idx_user_starred (user_id, starred),
    INDEX idx_user_archived (user_id, archived),
    INDEX idx_created_date (created_date DESC),
    INDEX idx_type_priority (type, priority)
);
```

## 注意事项

1. **用户隔离**: 通知严格按用户ID隔离，用户只能查看自己的通知
2. **自动标记**: 查看通知详情时自动标记为已读
3. **实时推送**: 配合WebSocket或SSE实现实时通知推送
4. **通知清理**: 定期清理已归档且超过30天的通知
5. **批量操作**: 批量操作需要检查权限，确保用户只能操作自己的通知
6. **关联对象**: relatedId和relatedType用于关联到具体的业务对象（扫描任务、制品等）
7. **分类逻辑**: category参数映射关系
   - `all`: 所有通知
   - `unread`: read=false
   - `starred`: starred=true
   - `archived`: archived=true
