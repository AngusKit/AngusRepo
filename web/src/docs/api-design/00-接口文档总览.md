## 通用接口规范

### 1. 请求规范

#### 基础URL
```
生产环境: https://api.angusrepo.com/api/v1
测试环境: https://test-api.angusrepo.com/api/v1
开发环境: http://localhost:8080/api/v1
```

#### 请求头
```http
Content-Type: application/json
Authorization: Bearer {access_token}
X-Tenant-ID: {tenant_id}
Accept-Language: zh-CN / en-US
```

#### HTTP方法
- `POST` - 创建资源
- `PUT` - 完整更新资源
- `PATCH` - 部分更新资源（可选）
- `DELETE` - 删除资源
- `GET` - 查询资源

### 2. 响应规范

#### 成功响应
```json
{
  "code": "S",
  "message": "成功",
  "data": {...},
  "timestamp": "1737270600000",
  "extensions": {}
}
```

#### 失败响应
```json
{
  "code": "E",
  "message": "错误信息",
  "data": null,
  "timestamp": "1737270600000",
  "extensions": {
    "errorCode": "REPO_001",
    "errorDetails": "仓库名称已存在"
  }
}
```

#### 分页响应
```json
{
  "code": "S",
  "message": "成功",
  "data": {
    "total": 100,
    "list": [...]
  },
  "timestamp": "1737270600000",
  "extensions": {}
}
```

#### HTTP状态码
- `200 OK` - 成功（GET、PUT）
- `201 Created` - 创建成功（POST）
- `204 No Content` - 删除成功（DELETE）
- `400 Bad Request` - 请求参数错误
- `401 Unauthorized` - 未认证
- `403 Forbidden` - 无权限
- `404 Not Found` - 资源不存在
- `409 Conflict` - 资源冲突
- `500 Internal Server Error` - 服务器错误

### 3. 分页参数

所有列表查询接口统一支持以下分页参数：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| page | Integer | 否 | 页码（从1开始） | 1 |
| size | Integer | 否 | 每页大小 | 10 |
| sort | String | 否 | 排序字段 | createdDate |
| order | String | 否 | 排序方向（asc/desc） | desc |

### 4. 审计字段

所有实体统一包含以下审计字段：

```java
public class BaseEntity {
    private String tenantId;              // 租户ID
    private String createdBy;             // 创建人ID
    private String creator;               // 创建人姓名
    private LocalDateTime createdDate;    // 创建时间
    private String modifiedBy;            // 修改人ID
    private String modifier;              // 修改人姓名
    private LocalDateTime modifiedDate;   // 修改时间
}
```

### 5. 校验注解

使用标准的Bean Validation注解，不添加message属性：

```java
@NotNull
@NotBlank
@NotEmpty
@Size(min = 1, max = 255)
@Email
@Pattern(regexp = "...")
```

### 6. 枚举定义

所有枚举类统一格式：

```java
public enum ExampleEnum {
    VALUE1("value1"),
    VALUE2("value2");
    
    private final String value;
    
    ExampleEnum(String value) {
        this.value = value;
    }
    
    public String getValue() {
        return value;
    }
}
```

### 7. JSON字段处理

使用JPA的JSON映射功能，直接将Java对象映射到数据库JSON字段，无需手动序列化：

```java
@Column(columnDefinition = "JSON")
private List<String> tags;

@Column(columnDefinition = "JSON")
private RepositorySettingsVo settings;
```

## 多租户架构

### 租户隔离策略

1. **数据库层隔离**
   - 所有表包含tenant_id字段
   - 所有查询自动添加tenant_id过滤
   - 外键关联需要包含tenant_id

2. **应用层隔离**
   - 请求头携带X-Tenant-ID
   - 从JWT token中提取租户ID
   - Spring AOP自动注入租户上下文

3. **存储层隔离**
   - Blob Store按租户ID分目录存储
   - 文件路径格式：`/{tenantId}/{repositoryId}/{path}`

## 安全规范

### 1. 认证授权
- 使用JWT Token认证
- Token过期时间：2小时
- Refresh Token过期时间：7天

### 2. 数据加密
- 敏感数据传输使用HTTPS
- 密码使用BCrypt加密
- API Token使用SHA256散列

### 3. 访问控制
- 基于RBAC的权限控制
- 仓库级别的访问控制
- API接口级别的权限验证

### 4. 安全审计
- 记录所有关键操作
- 敏感操作需要二次验证
- 异常登录告警
