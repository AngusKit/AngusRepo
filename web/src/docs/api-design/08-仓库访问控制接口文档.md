# 仓库访问控制接口文档

## 概述
本文档定义了仓库访问控制相关的RESTful API接口，包括权限规则管理、用户授权、Token管理等功能。

---

## 1. 创建访问规则

### 接口信息
- **接口路径**: `POST /api/v1/repositories/{repositoryId}/access-rules`
- **接口描述**: 为仓库创建访问规则
- **权限要求**: `REPOSITORY_ACCESS_MANAGE`

### 路径参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| repositoryId | String | 是 | 仓库ID |

### 请求参数

#### AccessRuleCreateDto
```java
public class AccessRuleCreateDto {
    @NotBlank
    private String name;
    
    private String description;
    
    @NotNull
    private AccessPrincipalType principalType;  // 主体类型
    
    @NotBlank
    private String principalId;                 // 主体ID
    
    @NotNull
    private List<AccessPermission> permissions; // 权限列表
    
    private List<String> paths;                 // 路径限制（可选）
    
    private LocalDateTime expiresAt;            // 过期时间（可选）
}
```

#### 枚举定义

**AccessPrincipalType（主体类型）**
```java
public enum AccessPrincipalType {
    USER("user"),               // 用户
    ROLE("role"),               // 角色
    GROUP("group"),             // 用户组
    TOKEN("token"),             // Token
    API_KEY("api_key");         // API Key
    
    private final String value;
}
```

**AccessPermission（权限）**
```java
public enum AccessPermission {
    READ("read"),               // 读取/下载
    WRITE("write"),             // 上传
    DELETE("delete"),           // 删除
    ADMIN("admin");             // 管理
    
    private final String value;
}
```

### 请求示例
```json
{
  "name": "开发团队读写权限",
  "description": "允许开发团队读写maven-releases仓库",
  "principalType": "GROUP",
  "principalId": "dev-team",
  "permissions": ["READ", "WRITE"],
  "paths": ["com/company/*"],
  "expiresAt": "2025-12-31T23:59:59"
}
```

### 响应参数

#### AccessRuleVo
```java
public class AccessRuleVo {
    private String tenantId;
    private String createdBy;
    private String creator;
    private LocalDateTime createdDate;
    private String modifiedBy;
    private String modifier;
    private LocalDateTime modifiedDate;
    
    private String id;
    private String repositoryId;
    private String name;
    private String description;
    private AccessPrincipalType principalType;
    private String principalId;
    private String principalName;
    private List<AccessPermission> permissions;
    private List<String> paths;
    private Boolean enabled;
    private LocalDateTime expiresAt;
    private Integer priority;               // 优先级
}
```

- **请求参数**: AccessRuleCreateDto
- **响应参数**: AccessRuleVo

## 3. 删除访问规则
- **接口路径**: `DELETE /api/v1/repositories/{repositoryId}/access-rules/{id}`
- **响应**: 204 No Content

## 4. 查询访问规则详情
- **接口路径**: `GET /api/v1/repositories/{repositoryId}/access-rules/{id}`
- **响应参数**: AccessRuleVo

## 5. 查询访问规则列表
- **接口路径**: `GET /api/v1/repositories/{repositoryId}/access-rules`
- **请求参数**: page, size, principalType, enabled
- **响应**: PageResponse<AccessRuleVo>

## 6. 创建访问Token

### 接口信息
- **接口路径**: `POST /api/v1/repositories/{repositoryId}/tokens`
- **接口描述**: 为仓库创建访问Token
- **权限要求**: `REPOSITORY_TOKEN_CREATE`

### 请求参数

#### AccessTokenCreateDto
```java
public class AccessTokenCreateDto {
    @NotBlank
    private String name;
    
    private String description;
    
    @NotNull
    private List<AccessPermission> permissions;
    
    private LocalDateTime expiresAt;        // 过期时间
    
    private List<String> ipWhitelist;       // IP白名单
}
```

### 响应参数

#### AccessTokenVo
```java
public class AccessTokenVo {
    private String tenantId;
    private String createdBy;
    private String creator;
    private LocalDateTime createdDate;
    
    private String id;
    private String repositoryId;
    private String name;
    private String description;
    private String token;                   // Token值（仅创建时返回）
    private String tokenHash;               // Token哈希
    private List<AccessPermission> permissions;
    private Boolean enabled;
    private LocalDateTime expiresAt;
    private LocalDateTime lastUsed;
    private Long usageCount;
    private List<String> ipWhitelist;
}
```

## 9. 检查用户权限

### 接口信息
- **接口路径**: `POST /api/v1/repositories/{repositoryId}/check-permission`
- **接口描述**: 检查用户对仓库或路径的访问权限
- **权限要求**: `REPOSITORY_VIEW`

### 请求参数

#### PermissionCheckDto
```java
public class PermissionCheckDto {
    private String userId;                  // 用户ID（为空则检查当前用户）
    private AccessPermission permission;    // 检查的权限
    private String path;                    // 制品路径（可选）
}
```

### 响应参数

#### PermissionCheckResultVo
```java
public class PermissionCheckResultVo {
    private Boolean hasPermission;
    private String reason;                  // 拒绝原因
    private List<String> matchedRules;      // 匹配的规则ID
}
```

## 10. 查询用户权限列表

### 接口信息
- **接口路径**: `GET /api/v1/repositories/{repositoryId}/user-permissions`
- **接口描述**: 查询用户在仓库中的所有权限
- **权限要求**: `REPOSITORY_VIEW`

### 请求参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userId | String | 否 | 用户ID（为空则查询当前用户） |

### 响应参数

#### UserPermissionsVo
```java
public class UserPermissionsVo {
    private String userId;
    private String userName;

    private String repositoryName;
    private List<AccessPermission> effectivePermissions;  // 生效的权限

```

## 数据库表设计

```sql
CREATE TABLE access_rule (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    repository_id VARCHAR(64) NOT NULL,
    name VARCHAR(255) NOT NULL,
    description TEXT,
    principal_type VARCHAR(50) NOT NULL,
    principal_id VARCHAR(255) NOT NULL,
    enabled BOOLEAN DEFAULT TRUE,
    expires_at TIMESTAMP,
    priority INT DEFAULT 0,
    
    -- JSON字段
    permissions JSON,
    paths JSON,
    
    created_by VARCHAR(64) NOT NULL,
    created_date TIMESTAMP NOT NULL,
    modified_by VARCHAR(64) NOT NULL,
    modified_date TIMESTAMP NOT NULL,
    
    UNIQUE KEY uk_repo_principal (repository_id, principal_type, principal_id, name),
    INDEX idx_tenant_repository (tenant_id, repository_id),
    INDEX idx_principal (principal_type, principal_id),
    
    FOREIGN KEY (repository_id) REFERENCES repository(id) ON DELETE CASCADE
);

CREATE TABLE access_token (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    repository_id VARCHAR(64) NOT NULL,
    name VARCHAR(255) NOT NULL,
    description TEXT,
    token_hash VARCHAR(255) NOT NULL,
    enabled BOOLEAN DEFAULT TRUE,
    expires_at TIMESTAMP,
    last_used TIMESTAMP,
    usage_count BIGINT DEFAULT 0,
    
    -- JSON字段
    permissions JSON,
    ip_whitelist JSON,
    
    created_by VARCHAR(64) NOT NULL,
    created_date TIMESTAMP NOT NULL,
    
    UNIQUE KEY uk_token_hash (token_hash),
    INDEX idx_tenant_repository (tenant_id, repository_id),
    
    FOREIGN KEY (repository_id) REFERENCES repository(id) ON DELETE CASCADE
);

CREATE TABLE access_log (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    repository_id VARCHAR(64) NOT NULL,
    user_id VARCHAR(64),
    permission VARCHAR(50) NOT NULL,
    path VARCHAR(1000),
    ip_address VARCHAR(50),
    user_agent VARCHAR(500),
    success BOOLEAN DEFAULT TRUE,
    error_message TEXT,
    access_time TIMESTAMP NOT NULL,
    
    INDEX idx_tenant_repository (tenant_id, repository_id),
    INDEX idx_access_time (access_time DESC),
    
    FOREIGN KEY (repository_id) REFERENCES repository(id) ON DELETE CASCADE
);
```

## 错误码

| 错误码 | 说明 |
|--------|------|
| ACCESS_001 | 访问规则不存在 |
| ACCESS_002 | Token不存在或已过期 |
| ACCESS_003 | IP地址不在白名单中 |
| ACCESS_004 | 无权限访问 |
| ACCESS_005 | Token已被撤销 |

## 注意事项

1. **权限优先级**: 多个规则匹配时，按priority降序匹配
2. **Token安全**: Token仅在创建时返回一次，需妥善保管
3. **过期检查**: Token和规则过期后自动失效
4. **审计日志**: 所有访问操作记录到access_log表
5. **IP白名单**: 支持CIDR格式（如192.168.1.0/24）
6. **权限继承**: 用户权限 = 用户直接权限 + 角色权限 + 用户组权限
