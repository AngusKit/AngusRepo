# 活动日志接口文档

## 概述
本文档定义了系统活动日志相关的RESTful API接口，包括日志记录、查询、导出等功能。

---

## 1. 创建活动日志

### 接口信息
- **接口路径**: `POST /api/v1/activity-logs`
- **接口描述**: 创建活动日志记录（通常由系统自动记录）
- **权限要求**: `ACTIVITY_LOG_CREATE`

### 请求参数

#### ActivityLogCreateDto
```java
public class ActivityLogCreateDto {
    @NotNull
    private ActivityAction action;          // 操作类型
    
    @NotBlank
    private String user;                    // 操作用户
    
    @NotBlank
    private String artifact;                // 操作对象
    
    @NotBlank
    private String repository;              // 仓库名称
    
    private String ipAddress;               // IP地址
    
    private String userAgent;               // User Agent
    
    private String details;                 // 详细信息
    
    private ActivityCategory category;      // 分类
}
```

#### 枚举定义

**ActivityAction（操作类型）**
```java
public enum ActivityAction {
    UPLOAD("upload"),
    DOWNLOAD("download"),
    DELETE("delete"),
    UPDATE("update"),
    CREATE("create"),
    USER_ADD("user_add"),
    USER_REMOVE("user_remove"),
    ROLE_CHANGE("role_change"),
    SCAN("scan"),
    ACCESS_GRANT("access_grant"),
    ACCESS_REVOKE("access_revoke"),
    CLEANUP("cleanup"),
    SETTINGS_UPDATE("settings_update");
    
    private final String value;
    
    ActivityAction(String value) {
        this.value = value;
    }
}
```

**ActivityCategory（分类）**
```java
public enum ActivityCategory {
    ARTIFACT("artifact"),
    REPOSITORY("repository"),
    USER("user"),
    SECURITY("security"),
    SYSTEM("system");
    
    private final String value;
    
    ActivityCategory(String value) {
        this.value = value;
    }
}
```

## 2. 查询活动日志详情

### 接口信息
- **接口路径**: `GET /api/v1/activity-logs/{id}`
- **接口描述**: 查询单条活动日志详情
- **权限要求**: `ACTIVITY_LOG_VIEW`

### 路径参数
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 日志ID |

### 请求参数
无

### 响应参数
返回完整的 `ActivityLogVo` 对象

## 3. 查询活动日志列表

### 接口信息
- **接口路径**: `GET /api/v1/activity-logs`
- **接口描述**: 分页查询活动日志列表，支持多维度筛选
- **权限要求**: `ACTIVITY_LOG_VIEW`

### 请求参数

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| page | Integer | 否 | 页码 | 1 |
| size | Integer | 否 | 每页大小 | 10 |
| search | String | 否 | 搜索关键词（制品、用户、仓库） | - |
| action | ActivityAction | 否 | 操作类型筛选 | - |
| user | String | 否 | 用户筛选 | - |
| repository | String | 否 | 仓库筛选 | - |
| category | ActivityCategory | 否 | 分类筛选 | - |
| startDate | LocalDateTime | 否 | 开始时间 | - |
| endDate | LocalDateTime | 否 | 结束时间 | - |
| sort | String | 否 | 排序字段 | timestamp |
| order | String | 否 | 排序方向 | desc |

### 请求示例
```
GET /api/v1/activity-logs?page=1&size=10&action=UPLOAD&user=Alex%20Chen&startDate=2024-01-01T00:00:00
```

## 5. 导出活动日志

### 接口信息
- **接口路径**: `GET /api/v1/activity-logs/export`
- **接口描述**: 导出活动日志为CSV或Excel文件
- **权限要求**: `ACTIVITY_LOG_EXPORT`

### 请求参数

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| format | String | 否 | 导出格式（csv/excel） | csv |
| action | ActivityAction | 否 | 操作类型筛选 | - |
| user | String | 否 | 用户筛选 | - |
| repository | String | 否 | 仓库筛选 | - |
| startDate | LocalDateTime | 否 | 开始时间 | - |
| endDate | LocalDateTime | 否 | 结束时间 | - |

### 请求示例
```
GET /api/v1/activity-logs/export?format=csv&startDate=2024-01-01T00:00:00&endDate=2024-01-31T23:59:59
```

### 响应参数
- **Content-Type**: text/csv 或 application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
- **Content-Disposition**: attachment; filename="activity-logs-20240119.csv"
- **响应内容**: 文件流

## 数据库表设计建议

### activity_log 表
```sql
CREATE TABLE activity_log (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    action VARCHAR(50) NOT NULL,
    user VARCHAR(255) NOT NULL,
    artifact VARCHAR(500) NOT NULL,
    repository VARCHAR(255) NOT NULL,
    timestamp TIMESTAMP NOT NULL,
    ip_address VARCHAR(50),
    user_agent VARCHAR(500),
    details TEXT,
    category VARCHAR(50) NOT NULL,
    
    created_by VARCHAR(64) NOT NULL,
    created_date TIMESTAMP NOT NULL,
    
    INDEX idx_tenant_timestamp (tenant_id, timestamp DESC),
    INDEX idx_tenant_action (tenant_id, action),
    INDEX idx_tenant_user (tenant_id, user),
    INDEX idx_tenant_repository (tenant_id, repository),
    INDEX idx_tenant_category (tenant_id, category),
    INDEX idx_timestamp (timestamp DESC),
    
    -- 分区表（按月分区，便于清理历史数据）
    PARTITION BY RANGE (YEAR(timestamp) * 100 + MONTH(timestamp)) (
        PARTITION p202401 VALUES LESS THAN (202402),
        PARTITION p202402 VALUES LESS THAN (202403),
        PARTITION p_max VALUES LESS THAN MAXVALUE
    )
);
```

## 注意事项

1. **自动记录**: 系统关键操作应自动记录活动日志，无需手动调用
2. **异步写入**: 日志记录应异步执行，避免影响主流程性能
3. **数据保留**: 建议保留最近90天的详细日志，更早的日志可以归档或删除
4. **分区表**: 使用分区表按月存储，便于管理和清理历史数据
5. **索引优化**: 按查询频率添加合适的索引
6. **隐私保护**: IP地址等敏感信息需脱敏处理
7. **导出限制**: 导出功能应限制数据量，避免内存溢出
8. **审计合规**: 关键操作日志应永久保留，满足审计要求
