# 安全扫描接口文档

## 概述
本文档定义了安全扫描相关的RESTful API接口，包括漏洞扫描、扫描任务管理、扫描策略配置等功能。

---

## 1. 创建扫描任务

### 接口信息
- **接口路径**: `POST /api/v1/security/scans`
- **接口描述**: 创建安全扫描任务
- **权限要求**: `SECURITY_SCAN_CREATE`

### 请求参数

#### ScanTaskCreateDto
```java
public class ScanTaskCreateDto {
    @NotNull
    private ScanTarget target;          // 扫描目标类型
    
    @NotBlank
    private String targetId;            // 目标ID（仓库ID或制品ID）
    
    private ScanType scanType;          // 扫描类型
    
    private ScanLevel scanLevel;        // 扫描级别
    
    private Boolean async;              // 是否异步执行
}
```

#### 枚举定义

**ScanTarget（扫描目标）**
```java
public enum ScanTarget {
    REPOSITORY("repository"),
    ARTIFACT("artifact"),
    SYSTEM("system");
    
    private final String value;
    
    ScanTarget(String value) {
        this.value = value;
    }
}
```

**ScanType（扫描类型）**
```java
public enum ScanType {
    VULNERABILITY("vulnerability"),      // 漏洞扫描
    LICENSE("license"),                  // 许可证扫描
    MALWARE("malware"),                  // 恶意软件扫描
    COMPLIANCE("compliance"),            // 合规性扫描
    COMPREHENSIVE("comprehensive");      // 综合扫描
    
    private final String value;
    
    ScanType(String value) {
        this.value = value;
    }
}
```

**ScanLevel（扫描级别）**
```java
public enum ScanLevel {
    QUICK("quick"),          // 快速扫描
    STANDARD("standard"),    // 标准扫描
    DEEP("deep");            // 深度扫描
    
    private final String value;
    
    ScanLevel(String value) {
        this.value = value;
    }
}
```

### 请求示例
```json
{
  "target": "REPOSITORY",
  "targetId": "1",
  "scanType": "VULNERABILITY",
  "scanLevel": "STANDARD",
  "async": true
}
```

## 8. 创建扫描策略

### 接口信息
- **接口路径**: `POST /api/v1/security/policies`
- **接口描述**: 创建安全扫描策略
- **权限要求**: `SECURITY_POLICY_CREATE`

### 请求参数

#### ScanPolicyCreateDto
```java
public class ScanPolicyCreateDto {
    @NotBlank
    private String name;                    // 策略名称
    
    private String description;             // 策略描述
    
    @NotNull
    private ScanTarget target;              // 应用目标
    
    private List<String> targetIds;         // 目标ID列表（为空则应用到所有）
    
    @NotNull
    private ScanType scanType;              // 扫描类型
    
    @NotNull
    private ScanLevel scanLevel;            // 扫描级别
    
    @NotNull
    private PolicySchedule schedule;        // 调度配置
    
    @NotNull
    private PolicyAction action;            // 执行动作
    
    private PolicyThreshold threshold;      // 阈值配置
    
    @NotNull
    private Boolean enabled;                // 是否启用
}
```

#### PolicySchedule
```java
public class PolicySchedule {
    private ScheduleType type;              // 调度类型

    private Integer intervalHours;          // 间隔小时数
}
```

## 数据库表设计建议

### scan_task 表
```sql
CREATE TABLE scan_task (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    target VARCHAR(50) NOT NULL,
    target_id VARCHAR(64) NOT NULL,
    target_name VARCHAR(255),
    scan_type VARCHAR(50) NOT NULL,
    scan_level VARCHAR(50) NOT NULL,
    status VARCHAR(50) DEFAULT 'PENDING',
    progress INT DEFAULT 0,
    start_time TIMESTAMP,
    end_time TIMESTAMP,
    duration BIGINT,
    error_message TEXT,
    
    -- JSON字段
    result JSON,                 -- ScanResultVo
    
    created_by VARCHAR(64) NOT NULL,
    created_date TIMESTAMP NOT NULL,
    modified_by VARCHAR(64) NOT NULL,
    modified_date TIMESTAMP NOT NULL,
    
    INDEX idx_tenant_status (tenant_id, status),
    INDEX idx_tenant_target (tenant_id, target, target_id),
    INDEX idx_created_date (created_date DESC)
);
```

### scan_policy 表
```sql
CREATE TABLE scan_policy (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    name VARCHAR(255) NOT NULL,
    description TEXT,
    target VARCHAR(50) NOT NULL,
    scan_type VARCHAR(50) NOT NULL,
    scan_level VARCHAR(50) NOT NULL,
    enabled BOOLEAN DEFAULT TRUE,
    last_executed TIMESTAMP,
    next_execution TIMESTAMP,
    execution_count INT DEFAULT 0,
    
    -- JSON字段
    target_ids JSON,             -- List<String>
    schedule JSON,               -- PolicySchedule
    action JSON,                 -- PolicyAction
    threshold JSON,              -- PolicyThreshold
    
    created_by VARCHAR(64) NOT NULL,
    created_date TIMESTAMP NOT NULL,
    modified_by VARCHAR(64) NOT NULL,
    modified_date TIMESTAMP NOT NULL,
    
    INDEX idx_tenant_enabled (tenant_id, enabled),
    INDEX idx_next_execution (next_execution)
);
```

### vulnerability 表
```sql
CREATE TABLE vulnerability (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    scan_task_id VARCHAR(64) NOT NULL,
    cve_id VARCHAR(100) NOT NULL,
    title VARCHAR(500),
    description TEXT,
    severity VARCHAR(50) NOT NULL,
    affected_artifact VARCHAR(255),
    affected_version VARCHAR(100),
    fixed_version VARCHAR(100),
    cvss_score DECIMAL(3, 1),
    published_date VARCHAR(50),
    
    -- JSON字段
    references JSON,             -- List<String>
    
    created_date TIMESTAMP NOT NULL,
    
    UNIQUE KEY uk_task_cve_artifact (scan_task_id, cve_id, affected_artifact),
    INDEX idx_tenant_severity (tenant_id, severity),
    INDEX idx_cve_id (cve_id),
    
    FOREIGN KEY (scan_task_id) REFERENCES scan_task(id) ON DELETE CASCADE
);
```

## 错误码定义

| 错误码 | 说明 |
|--------|------|
| SCAN_001 | 扫描任务不存在 |
| SCAN_002 | 扫描目标不存在 |

## 注意事项

1. **异步执行**: 扫描任务应异步执行，避免阻塞接口响应
2. **进度更新**: 扫描过程中定时更新进度状态
3. **结果缓存**: 扫描结果应缓存，避免重复扫描
4. **CVE数据库**: 需定期更新CVE漏洞数据库
5. **扫描引擎**: 集成第三方扫描引擎（如Trivy、Clair）
6. **通知机制**: 发现高危漏洞时及时通知相关人员
7. **策略调度**: 使用定时任务调度器执行策略
